
# Tecnologias usadas

As tecnologias utilizadas foram: HTML, CSS e JavaScript. Acredito que essas são as tecnologias que melhor rodam, por serem nativas na maioria dos navegadores modernos.

# Como inicializar o site:

Para inicializar, você precisa realizar um clone em seu computador:

```
git clone https://github.com/kaiqueferreiradz/desafio_cartao_de_visitas_digital.git
```

E então abrir o arquivo `index.html` em um navegador web.
